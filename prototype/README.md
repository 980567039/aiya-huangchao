# Prototype V0.3

当前实现范围：建国危局与五年求生。玩家以 20 岁新帝身份接手残破天下，在主城建设民营、兵营和伙房，处理分级急报，并在资源、势力和危机压力之间求生。

## 开发

```bash
npm install
npm run dev
```

打开终端提示的本地地址即可查看主城区界面。

## 验证

```bash
npm test
npm run build
```

当前原型已包含：建筑建设与升级、五州生产与中央征收、军粮军饷与行政消耗、资源短缺后果、月度经营日志、120 秒月度倒计时、分级朝堂急报、事件队列、势力取舍标签、危机压力和提前败局。技能树、即时战斗和完整历史评价仍在后续 Sprint。

## 每月怎么玩

1. 在倒计时结束前建设或升级主城建筑。倒计时为 120 秒，归零会自动结算；也可以点击“结算经营 · 进入下月”立即推进。
2. 月结先结算建筑产出与维护，再推进年月和皇帝年龄。
3. 首月必有“国初三司议”教学急报；第 2、3 月是低强度学习期，之后按局势分为平稳月 1–2 件、紧张月 2–4 件、危机月 4–6 件。
4. 急报出现后倒计时暂停，一次裁决一件，最多排队 8 件。每个方案都会显示受益与受损势力，并改变资源、势力或州情。
5. 国库或粮食归零不会立刻结束，但会累积欠饷、饥荒、治安和叛乱压力。第 4 月起，压力达到临界点可能触发民变、兵变、士族逼宫、豪强割据或国家崩溃。

因此，前期目标不是无脑点下个月，而是在有限的月度窗口里安排建设、留下粮饷储备、选择要得罪的势力，并为下一次急报做准备。稳健路线应能撑过前五年，连续错误决策可能在五年内亡国。
