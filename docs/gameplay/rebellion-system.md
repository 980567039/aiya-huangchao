# 叛乱与推翻系统 V0.1

## 核心原则

叛乱不是随机 Game Over，而是玩家过去决策累积的结果。

风险来源包括：

- 民心
- 治安
- 饥荒
- 土匪
- 地方忠诚
- 地方势力影响力
- 驻军
- 军队调动
- 其他势力满意度

## 州叛乱风险

V0.1 原型公式：

`Risk = clamp(100 - CitizenSatisfaction - LocalLoyalty*0.3 - Security*0.3 + BanditLevel*0.3 + FamineLevel*0.3 + LocalGentryInfluence*0.2, 0, 100)`

阶段：

- 0～29 稳定
- 30～49 不稳
- 50～69 骚乱
- 70～84 民变
- 85～100 高危

达到高危后仍进行概率判定，保留干预空间。

## 平叛

平叛需要消耗：

- 军队
- 粮食
- 兵器
- 国库

平叛成功也可能造成：

- 民心进一步下降
- 其他州驻军减少
- 武将影响力提高
- 皇权短期提高 / 长期下降

## 皇帝被推翻

推翻来源：

### 武将

军队规模高、军饷不足、武将满意度极低、皇权不足时，可能发生兵变或逼宫。

### 士族

士族影响力高、满意度极低、中央控制弱时，可能通过朝廷政变、废帝或拥立新君结束统治。

### 百姓

多个州民心崩溃、治安失控并形成大规模农民军时，可能攻入京城。

### 豪强 / 地方割据

地方势力长期失控时可能拒绝中央命令并形成事实割据，最终导致王朝崩溃。

## 结束后的评价

根据“谁推翻了皇帝、为什么推翻、之前30年做过什么”生成历史评价，而不是简单给 Game Over。
