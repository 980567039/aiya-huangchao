# 圣旨系统 V0.1

## 定位

圣旨是皇帝最主要的主动决策手段。每条圣旨都应该改变至少两个系统，并制造明确的机会成本。

## 第一批圣旨

| ID | 圣旨 | 主要收益 | 主要代价 |
|---|---|---|---|
| E001 | 加税 | 国库增加 | 百姓、豪强满意度下降 |
| E002 | 减税 | 百姓 / 豪强满意度上升 | 国库收入下降 |
| E003 | 赈灾 | 民心、治安恢复 | 粮食 / 国库下降 |
| E004 | 征兵 | 军队增加 | 粮食、兵器、百姓满意度 |
| E005 | 裁军 | 降低长期军费 | 武将满意度、军事能力下降 |
| E006 | 扩军 | 提升军力和威慑 | 国库、粮食、兵器长期压力 |
| E007 | 查税 | 增加短期税收、压制地方隐匿收入 | 士族 / 豪强不满 |
| E008 | 抄家 | 获得资产、提高皇权威慑 | 士族 / 豪强强烈不满 |
| E009 | 封赏武将 | 稳定军队、提升武将满意度 | 国库 / 皇权资源消耗 |
| E010 | 削弱武将 | 提高中央控制 | 武将满意度与军队稳定下降 |

## 执行

圣旨不是百分之百落地。执行效果受到：

- 皇权
- 地方忠诚
- 地方势力影响
- 官员能力
- 官员腐败
- 当前灾害 / 战乱

影响。

V0.1 暂用：

`ExecutionRate = clamp(50 + ImperialAuthority*0.3 + LocalLoyalty*0.2 - LocalGentryInfluence*0.1 - LocalPower*0.1, 20, 100)`

## 圣旨设计规则

1. 不设计“无脑最优”的圣旨。
2. 大多数强力政策必须产生长期副作用。
3. 玩家应能通过政策形成自己的统治风格。
4. 圣旨是“政治选择”，不是单纯的属性加减。
