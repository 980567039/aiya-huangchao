# 《哎呀，朕的皇朝怎么又亡啦》政策路线与技能树 V0.2

> 状态：设计基线
> 版本：V0.2
> 日期：2026-08-26

## 1. 设计目标

政策路线是本作的核心爽点之一。

玩家不是单纯从固定政策按钮中选择，而是在30年的统治过程中逐渐形成自己的“治国之道”。技能树的价值不是简单提供属性加成，而是**解锁新的政治手段、改变事件处理方式、创造新的资源获取方式**。

核心体验：

> “我本来想做仁君，但国库没钱了，只能向豪强募捐；后来豪强越来越不听话，我又学会了集权；最后为了平叛不得不依靠武将。”

因此路线允许混合发展，不强制玩家只走一条路线。

---

## 2. V0.2 四大路线

第一版正式路线：

1. 仁政 —— 民心、长期稳定、以政治声望换取资源
2. 集权 —— 中央控制、圣旨执行、削弱地方势力
3. 暴政 —— 强制获取资源、镇压、没收、恐惧统治
4. 强兵 —— 军队、战争、军功、军事威慑

后续可扩展：富国、改革、宗教、商业、外交等，但V0.2不加入。

---

## 3. 技能树基本规则

### 3.1 技能点

- 每年获得基础技能点。
- 达成特殊统治成就可以获得额外技能点。
- 重大危机、战争、改革等可以产生额外技能点奖励。

V0.2建议：

- 每年基础 2 点
- 30年基础最多约60点
- 单个技能成本 1～5点

### 3.2 解锁

技能存在前置关系。

例如：

`仁政 → 天下共济 → 以粮代税 → 天下归心`

玩家可以跨路线，但高级技能通常需要：

- 前置技能
- 足够技能点
- 皇权 / 民心 / 军力等状态条件
- 特定历史事件条件

### 3.3 主动技能

主动技能本质上是“特殊圣旨”。

玩家在奏折 / 朝政界面使用。

每个主动技能必须具有：

- 即时效果
- 资源成本
- 势力影响
- 冷却或使用限制
- 潜在长期副作用

### 3.4 被动技能

改变系统规则，例如：

- 灾害民心损失降低
- 圣旨执行率提高
- 军粮消耗降低
- 镇压效率提高
- 特定事件出现概率改变

### 3.5 终极技能

每条路线1个核心终极技能。

不是“全属性+20”，而是允许皇帝短时间做一件平时做不到的事情。

# 4. 仁政路线

## 核心幻想

> “朕不需要压服天下，朕要让天下愿意跟着朕。”

核心优势：

- 民心
- 灾害处理
- 长期稳定
- 通过声望换资源
- 降低百姓叛乱风险

核心弱点：

- 直接榨取资源能力弱
- 军事扩张能力一般
- 财政紧张时容易陷入困境

### R1 爱民如子

类型：被动

效果：灾害、饥荒造成的百姓满意度下降降低20%。

### R2 宽以待人

类型：被动

效果：百姓满意度低于40时，民变风险增长速度降低15%。

### R3 天下共济

类型：主动圣旨

效果：向士族、豪强发布自愿募捐诏令。

收益：国库 +3000～8000，粮食 +1000～4000。

代价：皇权 -1，士族满意度 -2，豪强满意度 -4。

特殊：高民心、高皇权时更容易出现主动捐献事件，实际代价下降。

冷却：12个月。

### R4 轻徭薄赋

类型：主动

效果：未来3个月百姓税负下降20%，百姓满意度 +8～12。

代价：国库税收下降15%。

### R5 以粮代税

类型：主动 / 制度

效果：允许部分地区以粮食替代货币税收。

收益：粮食收入增加，百姓满意度 +5。

代价：货币税收下降。

特殊：粮食富余的州效果更强。

### R6 天下归心

类型：终极技能

前置：爱民如子、天下共济、以粮代税。

效果：持续6个月：

- 全国民变风险大幅下降
- 百姓满意度缓慢恢复
- 征兵造成的民心损失降低50%
- 奏折中“百姓请愿”事件减少

代价：使用后进入36个月冷却；使用期间不能执行部分极端镇压类政策。

# 5. 集权路线

## 核心幻想

> “天下的事，只有朕说了算。”

核心优势：

- 圣旨执行率
- 中央控制
- 降低地方势力影响力
- 快速响应危机

核心弱点：

- 容易同时得罪多个政治集团
- 行政成本高
- 过度集权会增加官僚腐败和皇帝负担

### C1 皇命如山

类型：被动

效果：圣旨基础执行率 +10%。

### C2 钦差巡按

类型：主动

效果：选择一个州进行中央调查。

可能发现：

- 贪腐
- 隐田
- 军费侵吞
- 豪强违法
- 地方官与势力勾结

代价：国库、政治资本。

### C3 密奏制度

类型：制度

效果：增加独立奏折来源，降低地方官隐瞒事件的概率。

代价：官员体系不满略微增加。

### C4 军政分离

类型：主动 / 制度

效果：降低地方武将影响力，提高中央控制。

代价：武将满意度 -10～15。

### C5 中央直辖

类型：主动

效果：指定一个州进入中央直辖状态：地方势力影响力下降，圣旨执行率提高。

代价：每月行政成本增加。

### C6 天威独断

类型：终极技能

效果：未来3个月，皇帝可以无视一次高阻力政策条件，强制执行一次圣旨，并显著提高执行率。

代价：使用后所有非皇权势力获得“警惕”状态，满意度轻微下降。

# 6. 暴政路线

## 核心幻想

> “既然他们不愿意给，那朕就自己拿。”

核心优势：

- 短期资源爆发
- 快速解决危机
- 镇压叛乱
- 强制政策

核心弱点：

- 势力不满快速累积
- 长期叛乱风险高
- 容易形成联合反抗

### T1 铁腕

类型：被动

效果：皇权低于40时，强制圣旨执行率 +10%。

### T2 强行征税

类型：主动

效果：立即获得国库 +5000。

代价：百姓满意度 -8，豪强满意度 -6，民心 -10。

冷却：12个月。

### T3 抄没家产

类型：主动

效果：指定一个士族或豪强目标，获得其部分财富。

代价：目标势力满意度 -15～25；其他相关势力获得恐惧与警惕。

### T4 强征军粮

类型：主动

效果：立即获得粮食。

代价：指定州民心下降，地方治安下降。

### T5 株连九族

类型：高阶主动

触发：指定势力发生叛乱或重大政治案件。

效果：大幅降低当前叛乱。

代价：多个势力满意度下降，暴政度提高，后续反抗事件概率提高。

### T6 天威如狱

类型：终极技能

效果：全国进入“恐惧统治”6个月：

- 叛乱立即降低
- 强制政策执行率极高
- 征税 / 征兵效率提高

代价：结束后进入“积怨爆发”窗口，所有非皇权势力的不满会被重新计算并可能触发连续事件。

# 7. 强兵路线

## 核心幻想

> “天下若敢乱，朕便以百万雄兵定之。”

核心优势：

- 军队
- 平叛
- 战争
- 外交威慑
- 军事收益

核心弱点：

- 粮食和兵器压力
- 国库压力
- 武将势力不断壮大
- 战争可能制造长期负债

### M1 募兵令

类型：被动

效果：征兵成本降低15%，军队增长提高。

### M2 军屯

类型：制度

效果：军队部分粮食消耗由军屯承担，降低中央粮食压力。

代价：部分州农业产出下降。

### M3 军功爵

类型：制度

效果：战争胜利后获得额外威望和军队满意度。

代价：武将影响力增长速度提高。

### M4 军器监

类型：制度

效果：兵器生产效率提高20%。

代价：国库行政成本增加。

### M5 远征

类型：主动

允许将特定外交 / 海外事件转化为战争行动。

效果：解锁高收益战争事件。

代价：粮食、兵器、军队、国库。

### M6 天下无敌

类型：终极技能

效果：持续12个月：

- 平叛效率大幅提高
- 战争成功率提高
- 外敌威胁降低
- 武将满意度提高

代价：军队消耗增加；武将影响力显著增长。

# 8. 跨路线组合

路线不能简单互斥。玩家可以混合投资。

## 仁政 + 集权

典型皇帝：改革型中兴之主。

玩法：

> 先安民，再整顿地方。

优势：稳定且长期。

弱点：见效慢，缺钱时容易难受。

## 集权 + 暴政

典型皇帝：铁腕皇帝。

玩法：

> 通过制度和强制手段快速集中权力。

优势：行政效率极高。

弱点：容易引发政治联合反抗。

## 集权 + 强兵

典型皇帝：军政改革型雄主。

玩法：

> 中央牢牢控制军队，再对外扩张。

优势：战争能力强且武将不容易完全失控。

弱点：财政压力极高。

## 暴政 + 强兵

典型皇帝：战争暴君。

玩法：

> 用战争和掠夺维持帝国。

优势：短期资源和军力极强。

弱点：百姓、士族、豪强可能形成联合叛乱。

## 仁政 + 强兵

典型皇帝：仁武之君。

玩法：

> 国内安民，对外用兵。

优势：战争期间国内稳定。

弱点：军费和粮食压力仍然存在。

# 9. 技能与势力关系

技能效果必须进入统一的政治模型，而不是独立计算。

例如《天下共济》：

```text
基础募捐金额
× 士族满意度修正
× 豪强满意度修正
× 民心修正
× 皇权修正
```

因此同一个技能在不同皇帝手中表现不同。

例如：

### 皇权80、民心80

《天下共济》：

> “天下闻诏，豪商争相捐输。”

收益较高。

### 皇权35、民心30

《天下共济》：

> “诏令下达，地方士绅阳奉阴违。”

收益极低，甚至可能触发特殊事件。

这使技能树与国家模拟真正结合起来。

# 10. 路线倾向与最终评价

游戏不显示一个简单的“仁政值=80，所以你是仁君”。

系统记录玩家实际使用过的政策。

统计：

- 仁政行为次数
- 集权行为次数
- 暴政行为次数
- 强兵行为次数
- 镇压次数
- 战争次数
- 赈灾次数
- 加税次数
- 抄家次数
- 平均民心
- 平均军心
- 平均国库
- 最终领土 / 州稳定
- 是否发生大规模叛乱
- 谁最终推翻皇帝

最终生成“统治画像”。

例如：

> **仁始暴终**
>
> 即位之初轻徭薄赋，救济灾民；晚年国库空虚，屡行抄没。虽保社稷于一时，终使士族与豪强离心。

或者：

> **铁腕中兴**
>
> 帝在位三十年，整饬吏治，削弱地方，平定三次大乱。虽手段严酷，然终使天下复归中央。

# 11. V0.2 暂不确定数值

以下参数先允许在试玩中调整，不在当前阶段锁死：

- 每年技能点具体数量
- 技能冷却
- 各技能资源收益
- 势力满意度变化幅度
- 终极技能解锁年份
- 跨路线技能限制

原则：

> **先验证“技能是否让玩家爽”，再平衡数值。**

# 12. 程序实现建议

技能应数据驱动，不要将每个技能硬编码成独立逻辑。

建议字段：

```json
{
  "id": "benevolence_common_good",
  "route": "benevolence",
  "tier": 2,
  "type": "active_edict",
  "name": "天下共济",
  "cost": {
    "authority": 1
  },
  "cooldown_months": 12,
  "effects": [],
  "faction_modifiers": [],
  "prerequisites": ["benevolence_loving_people"],
  "conditions": [],
  "event_hooks": [],
  "tags": ["donation", "benevolence", "edict"]
}
```

后续可以让技能、圣旨、事件共用 Effect 系统。

推荐统一模型：

`Skill → Action → Effect → State Change → Event Hook`

这样未来增加50、100甚至200个技能时，不需要重新设计程序架构。
