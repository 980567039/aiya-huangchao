# 奏折系统 V0.1

## 定位

奏折是地方与中央之间的主要信息通道，也是玩家理解事件、人物和利益冲突的主要入口。

本作不是“猜真假”的玩法：玩家可以看到国家核心数值，但奏折会提供**带立场、带请求、带利益关系的解释**。

## 奏折字段

- ReportID
- ProvinceID
- EventID
- SourceCharacter
- Severity
- Summary
- Request
- EstimatedImpact
- PoliticalStake
- RelatedFaction
- CreatedTurn

## 奏折示例

> 江南巡抚奏：今岁水患虽重，然士绅多有赈济之举，请暂缓清查田亩，以安地方。

玩家可以看到江南州真实的粮食、民心、财政等数值，然后判断这个请求主要保护谁的利益。

## 奏折类型

- 灾情奏报
- 财政奏报
- 军务奏报
- 民情奏报
- 官员弹劾
- 势力请愿
- 战争 / 外交奏报
- 紧急军情

## 玩家操作

V0.1 支持：

- 批准请求
- 驳回请求
- 发布替代圣旨
- 要求调查
- 暂缓处理

奏折不一定要求玩家立即处理。拖延本身也是决策，并可能改变后续状态。
