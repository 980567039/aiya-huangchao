# 五大势力系统 V0.1

## 五大势力

| 势力 | 核心利益 | 主要矛盾 |
|---|---|---|
| 皇权 | 中央集权、稳定 | 与所有独立势力存在潜在矛盾 |
| 士族 | 官职、土地、政治权力 | 与皇权、百姓、豪强政策冲突 |
| 武将 | 军饷、军权、军功 | 与财政、士族、皇权存在冲突 |
| 百姓 | 粮食、低税、治安 | 与税收、豪强、战争存在冲突 |
| 豪强 | 土地、财富、商业、自治 | 与中央税制和百姓利益冲突 |

## 两个核心属性

### Satisfaction

范围 0～100，表示势力当前满意程度。

- 80～100：拥护
- 60～79：满意
- 40～59：中立
- 20～39：不满
- 0～19：极度不满

### Influence

范围 0～100，表示势力把政治不满转化为实际行动的能力。

影响力不会简单等于满意度。例如百姓满意度低但组织能力有限时可能只是骚乱；武将满意度低且军权高时可能直接政变。

## 势力变化

政策效果 = 基础效果 × 政策执行程度 + 状态修正。

每月满意度可以同时受到：

- 玩家圣旨
- 资源价格 / 稀缺
- 战争
- 灾害
- 事件
- 官员行为
- 其他势力变化

影响力主要受到长期结构变化影响，例如军队扩张会提高武将影响力，土地集中会提高豪强影响力，中央改革会提高皇权并降低地方势力空间。

## 设计原则

五大势力不追求永久和平。玩家应该不断面对：

> “我现在要满足谁？”

而不是：

> “如何让所有人都满意？”

## 推翻皇帝

当某势力满意度极低、影响力足够高，并且国家状态允许行动时，该势力可能触发推翻事件。

推翻方式：

- 武将：兵变、逼宫、拥立新君
- 士族：废帝、摄政、政变
- 百姓：大规模农民起义、攻破京城
- 豪强：地方割据并拒绝中央

皇权本身不是一个独立“敌对势力”，而是玩家控制的中央权力指标。
