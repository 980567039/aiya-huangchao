# 事件系统 V0.3

> Prototype V0.3 已将本文件的核心规则接入可运行 demo：每月生成分级朝堂急报，玩家选择方案后才恢复月度倒计时。

## 事件分类

1. 自然灾害：旱灾、洪灾、蝗灾
2. 民生：粮荒、土匪、民变
3. 政治：官员贪腐、士族冲突、豪强抗税
4. 军事：军队欠饷、边患
5. 外交 / 战争：贸易、海外机会、对外战争

## 触发原则

事件采用“基础概率 + 条件修正 + 世界状态修正”。

不是纯随机。

在 prototype 中采用“分级密度 + 状态加速”：

- 第 1 月必定触发一件教学急报，帮助玩家理解资源、势力与取舍。
- 平稳月生成 1–2 件，紧张月生成 2–4 件，危机月生成 4–6 件；第 2、3 月只生成低强度学习事件。
- 粮食、国库、治安、民心、势力满意度或叛乱风险进入危险区时，事件密度自动升级。
- 急报最多排队 8 件，一次裁决一件；超出队列的急报延后并增加危机压力。
- 每个选项都包含 `benefits` 与 `costs` 势力元数据，且至少拥有一个实际状态效果。

每月还拥有一个 120 秒倒计时。倒计时归零自动执行完整月结，玩家可用“结算经营 · 进入下月”手动提前触发。急报等待裁决时倒计时暂停，选择方案后恢复。

例如：

`粮食 < 50 → 粮荒概率提高`

`治安 < 60 → 土匪概率提高`

`国库不足以支付军费 → 欠饷概率提高`

## 链式事件

事件可以产生状态，而状态提高后续事件概率。

典型链：

`旱灾 → 粮食下降 → 粮荒 → 民心下降 → 治安下降 → 土匪 → 税收下降 → 国库下降 → 军队欠饷`

## 战争事件

战争属于事件系统，不做即时战斗。

例如“东瀛内乱”事件可以提供是否出兵的选择。

出兵可能获得白银、威望和贸易利益，但消耗粮食、兵器、军队与国库，并可能造成国内势力不满。

战争结果由军事力量、后勤、将领能力、准备程度和事件修正自动计算。

## 事件设计要求

每个重要事件至少提供两个可理解的处理方向，并保证选择会改变后续国家状态。

当前原型已落地 25 件可玩事件（EV000–EV024），覆盖天灾、民生、财政、军事、政治、外交、宫廷与天象。方案效果会写入资源、势力、州情与历史日志；部分方案还会生成链式急报。
