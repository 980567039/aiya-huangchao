# 事件系统 V0.1

## 事件分类

1. 自然灾害：旱灾、洪灾、蝗灾
2. 民生：粮荒、土匪、民变
3. 政治：官员贪腐、士族冲突、豪强抗税
4. 军事：军队欠饷、边患
5. 外交 / 战争：贸易、海外机会、对外战争

## 触发原则

事件采用“基础概率 + 条件修正 + 世界状态修正”。

不是纯随机。

例如：

`粮食 < 50 → 粮荒概率提高`

`治安 < 60 → 土匪概率提高`

`国库不足以支付军费 → 欠饷概率提高`

## 链式事件

事件可以产生状态，而状态提高后续事件概率。

典型链：

`旱灾 → 粮食下降 → 粮荒 → 民心下降 → 治安下降 → 土匪 → 税收下降 → 国库下降 → 军队欠饷`

## 战争事件

战争属于事件系统，不做即时战斗。

例如“东瀛内乱”事件可以提供是否出兵的选择。

出兵可能获得白银、威望和贸易利益，但消耗粮食、兵器、军队与国库，并可能造成国内势力不满。

战争结果由军事力量、后勤、将领能力、准备程度和事件修正自动计算。

## 事件设计要求

每个重要事件至少提供两个可理解的处理方向，并保证选择会改变后续国家状态。
