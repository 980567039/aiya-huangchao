# 《哎呀，朕的皇朝怎么又亡啦》月度游戏循环 V0.4

> 版本：V0.4  
> 状态：核心模拟循环设计基线

## 1. 目标

把资源、五州、四大普通势力、皇权、圣旨、奏折、事件、技能、叛乱串成连续运行的月度模拟循环。

玩家不管理真实地图上的每一座城市。地方问题通过“州级状态 + 奏折”上报到主城区。

最终游戏：约30年 = 360个月。玩家20岁登基，正常完成约30年后结束。

**Prototype 可以使用更短测试周期。**

## 2. 时间单位

### 月

月是核心模拟单位，一个月完成一次完整国家结算。

### 季度

每3个月触发季度型统计、税收修正、部分政策结算。

### 年

每12个月：

- 获得年度技能点
- 年度财政结算
- 年度人口变化
- 年度评价记录
- 年度重大事件概率修正

### 30年

360个月后正常退位并生成历史评价。提前死亡、政变、全国性叛乱成功等则提前结束。

## 3. 每月完整流程

```text
月初
 ↓
① 时间推进
 ↓
② 州生产
 ↓
③ 国家资源收入
 ↓
④ 国家资源消耗
 ↓
⑤ 势力状态更新
 ↓
⑥ 州状态更新
 ↓
⑦ 技能/政策持续效果
 ↓
⑧ 随机事件判定
 ↓
⑨ 事件生成奏折
 ↓
⑩ 玩家阅读奏折
 ↓
⑪ 玩家做出决策
 ↓
⑫ Action → Effect
 ↓
⑬ 后续事件 / 奏折生成
 ↓
⑭ 叛乱 / 政变判定
 ↓
⑮ 月末统计与历史记录
 ↓
进入下月
```

## 4. ① 时间推进

月份 +1，更新皇帝年龄、年份、月份、技能冷却、圣旨持续时间、Modifier、战争和事件持续时间。

**皇帝初始年龄：20岁。**

Prototype 若使用不同年龄，仅允许作为明确标记的实验值，不得作为正式规则。

## 5. ② 州生产

五州分别生产基础资源。每州至少计算粮食、财政、人口增长、治安。

```text
实际产出 = 基础产出
         × 人口修正
         × 治安修正
         × 临时Modifier
         × 灾害修正
```

州之间不需要真实地理运输模拟。中央重点关心每州本月向朝廷上缴多少。

## 6. ③ 国家资源收入

```text
中央财政收入 = 各州财政产出 × 中央征收效率
中央粮食收入 = 各州粮食产出 × 粮税效率
```

中央征收效率受皇权、士族影响、豪强影响、贪腐、地方忠诚和集权技能影响。

## 7. ④ 国家资源消耗

每月自动计算军粮、行政成本以及战争额外消耗。

资源不足不直接 Game Over，而是产生连锁后果：

```text
军饷不足 → 武将不满
粮食不足 → 民心下降
行政经费不足 → 腐败上升
兵器不足 → 战争能力下降
```

## 8. ⑤ 势力状态更新

每月更新四大普通势力：士族、武将、百姓、豪强。

每个势力至少拥有：

```text
satisfaction
influence
wealth
organization
resentment
fear
```

皇权是国家核心属性，不作为第五个普通势力参与同一套满意度模型。

**满意度和影响力完全分开。**

## 9. 满意度与积怨

满意度由圣旨、技能、事件选择、资源分配、战争、灾害、税收、征兵、官职任命和其他势力得利等行为累积产生。

```text
本月满意度变化
= 政策影响 + 事件影响 + 资源影响 + 环境影响 + 历史Modifier
```

长期受损会增加 `resentment`：

```text
满意度 < 40 → 每月积怨 +1
满意度 < 25 → 每月积怨 +2
满意度 > 60 → 积怨缓慢下降
```

## 10. ⑥ 州状态更新

每州更新：

- security
- morale
- corruption
- local_loyalty
- rebellion_risk
- faction influence

地方问题通过州级状态影响奏折和事件，而不是要求玩家直接操作城市。

## 11. ⑦ 技能 / 政策持续效果

检查持续中的技能、圣旨、制度、战争、灾害和临时 Buff/Debuff。

政策路线包括仁政、集权、暴政、强兵。技能应提供新的政治选择和代价，而不是单纯数值加成。

## 12. ⑧ 随机事件判定

事件采用：

```text
基础概率
× 州状态修正
× 国家状态修正
× 势力状态修正
× 历史Modifier
```

事件应受世界状态影响，使治理可以降低风险但不能完全控制命运。

## 13. 事件产生方式

事件发生后通常转化为奏折进入玩家决策窗口。

例如旱灾可以产生士族、豪强、百姓和武将各自不同的请求。重点不是猜真假，而是理解政治利益并做选择。

## 14. ⑨ 奏折生成规则

奏折来源包括州官、武将、士族、豪强、百姓代表、钦差、战场、外交和特殊事件。

同一个问题可以产生不同势力的不同解决方案。

## 15. ⑩ 玩家决策窗口

玩家可以：

- 批准奏折
- 驳回奏折
- 修改方案
- 发布圣旨
- 使用政策技能
- 调拨资源
- 暂不处理

平稳月份应较轻松，危机月份才形成连续决策压力。

## 16. ⑪ Action → Effect

```text
Action
 ↓
检查条件
 ↓
计算公式
 ↓
生成 Effects
 ↓
修改国家 / 州 / 势力状态
 ↓
记录历史日志
```

所有重要玩家行为都应尽量通过统一 Effect 系统改变状态，避免在 UI 中散落修改规则。

## 17. ⑫ 后续事件

重要决策不是立即结束，可以创建后续事件。

例如：

```text
赈灾 → 百姓满意 → 粮食下降 → 数月后粮荒
```

或：

```text
抄没豪强 → 国库增加 → 豪强积怨 → 豪强密谋 → 资助土匪
```

## 18. ⑬ 叛乱判定

叛乱不是单一数值超过阈值就必然发生。

```text
rebellion_score
= dissatisfaction
+ resentment
+ organization
+ local_influence
+ security_penalty
+ event_bonus
- imperial_suppression
- fear
```

阶段：

- 0～39：正常
- 40～59：紧张
- 60～79：危险
- 80～99：临界
- 100+：爆发

达到临界仍可保留概率与干预窗口。

## 19. 不同势力的反抗方式

四大势力不能全部使用同一种“造反”。

- 百姓：流民 → 土匪 → 民变 → 农民军 → 州级叛乱
- 豪强：抗税 → 拒绝执行圣旨 → 资助土匪 → 地方割据
- 士族：政治阻挠 → 联合官员 → 逼宫 → 政变
- 武将：拒绝军令 → 拥兵自重 → 兵变 → 京营 / 地方军事政变

平叛消耗军队、粮食和兵器，并可能造成其他州防务下降。

## 20. 月末记录

每月记录：

- 国家资源变化
- 五州状态变化
- 四大势力满意度 / 影响力变化
- 关键事件
- 玩家圣旨和 Action
- 叛乱风险
- 历史评价相关指标

这些记录既用于玩家历史回顾，也用于最终30年评价。

## 21. Prototype 验证重点

当前 Demo 可以缩短游戏周期，以验证：

1. 月度循环是否有趣
2. 玩家是否感受到势力冲突
3. 资源是否产生压力
4. 事件是否产生连续后果
5. 玩家是否有艰难抉择
6. 叛乱是否既可预警又不可完全控制

Prototype 的测试周期不改变最终30年游戏设计。
