# Current State — 当前项目实际状态

> 本文件描述 Prototype 当前真实实现状态，不代表最终游戏设计。
> 如果与最终 GDD 不同，应明确标注“Prototype 当前实现”。

## 当前版本

**Prototype V0.1 / 当前实现以仓库代码为准**

## 当前原型已确认的特点

- 皇帝初始年龄：20岁
- 当前原型用于短周期生存测试
- 当前 Prototype 与最终“30年一局”的设计目标区分开
- 游戏以月为时间推进单位
- 主城区是玩家主要操作空间
- 地方问题通过州级信息、事件、奏折等方式传达到主城区
- 五州模型保留
- 四大核心势力模型保留

## 当前开发原则

当前阶段优先验证：

1. 月度循环是否有趣
2. 玩家是否会在势力利益之间产生艰难抉择
3. 资源是否产生压力
4. 事件是否能够形成后续影响
5. 叛乱风险是否能够形成可控但紧张的危机

## 与最终设计的关系

最终目标仍然是：

- 一局约30年
- 皇帝最终退位或提前被推翻
- 根据30年统治表现生成历史评价
- 政策路线成为长期成长和玩法差异的重要来源

Prototype 可以为了测试采用更短的时间跨度、更少的事件、更简化的数值和临时 UI。

## 更新规则

当 Prototype 的实际玩法发生变化时，必须检查：

- `docs/GDD.md`
- `docs/gameplay/`
- `docs/development/`
- `data/`
- `README.md`

如果只是临时实验，不应把实验值直接写成最终设计。

如果用户正式确认新的玩法，则按照 `docs/project/change-management.md` 同步。
