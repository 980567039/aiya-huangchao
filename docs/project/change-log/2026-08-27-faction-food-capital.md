# 2026-08-27 Gameplay Change — 势力、主城建筑、粮食压力

## 用户确认的规则变化

### 1. 四大势力初始满意度

新游戏开始时：

- 士族：100
- 武将：100
- 百姓：100
- 豪强：100

理由：新皇登基初期各方默认支持新君。玩家从稳定状态开始，再通过政策和事件制造政治矛盾。

### 2. 势力是王朝崩溃的直接原因

四大势力不是普通信息卡，而是核心生存系统。

界面必须优先展示：

- 满意度
- 满意度趋势 / 风险
- 当前态度
- 影响力
- 积怨

最低势力满意度应进入危机压力计算。

### 3. 主城建筑

主城改为多个独立建筑，每个建筑独立升级，当前 Prototype 共六类：

- 官仓
- 国库
- 兵营
- 武库
- 工部作坊
- 市舶司

每座建筑 Lv.1～Lv.5，各自拥有建设 / 升级成本、月度产出和月度维护。

### 4. 军队与兵营粮耗

每月：

```text
军队粮耗 = 军队人数 × 0.05
兵营粮耗 = 兵营等级 × 300
```

如果粮食不足：

1. 粮食归零
2. 损失部分农民人口
3. 损失部分士兵
4. 百姓满意度下降
5. 武将满意度下降
6. 地方民心和叛乱风险进一步恶化

粮荒不是立即结束游戏，而是资源危机转化成政治危机。

## 设计同步要求

GDD / Gameplay 文档后续修改时必须保持上述规则一致。任何 Agent 看到本变更记录，都不得恢复旧的：

- 初始满意度 45～50
- 三建筑 `民营 / 兵营 / 伙房`
- 皇权作为第五普通势力
- 兵营或军队不消耗粮食
