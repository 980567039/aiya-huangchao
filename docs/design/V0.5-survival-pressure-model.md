# V0.5「生存压力模型」

> 目标：把 Demo 从“资源自然增长模拟器”推进为“皇帝生存决策游戏”。
>
> 核心原则：玩家不能靠什么都不做获得越来越富的安全局面；每个月都必须在资源、民力、建设和四大势力之间做取舍。

## 1. V0.5 验收目标

1. 不建任何建筑，连续 12 个月不能让国家资源稳定净增长。
2. 粮食、国库、兵器、民力至少有两项在正常经营下会形成持续压力。
3. 四大势力初始满意度均为 100，且事件/政策会造成明确且不可忽略的利益冲突。
4. 满意度 58.15 不能 Game Over；只有达到反叛触发条件后才进入叛乱链。
5. 每个事件选项必须显示“当前值 → 结算后值”，并明确资源、势力、州的正负变化。
6. 建筑必须是多实例：同类建筑可以建造多座，每座独立升级。
7. 民力必须成为建设和大型工程的核心成本。

## 2. 国家经济循环

```text
五州基础产出
   ↓
国家收入/粮食
   ↓
建筑与政策提高效率
   ↓
更多收入
   ↓
同时增加维护成本
   ↓
军队、工程、灾害、事件继续消耗资源
```

**关键限制：基础收入只负责维持最低运转，不负责让玩家自动变富。**

### 建议月度结算顺序

1. 事件/奏折决策
2. 建筑产出
3. 建筑维护
4. 军队粮耗
5. 民营粮耗与民力产出
6. 地方基础税粮/财赋
7. 工程与占用民力结算
8. 粮荒检查
9. 势力满意度/积怨更新
10. 叛乱判定
11. 月末日志

## 3. 核心资源

| 资源 | 用途 | 设计原则 |
|---|---|---|
| 国库 | 建筑、军费、工程、事件 | 不应自然无限增长 |
| 粮食 | 百姓、军队、建筑、赈灾 | 最重要的硬性生存资源之一 |
| 兵器 | 训练/战争/补充军队 | 战争前必须准备 |
| 军队 | 平叛、战争 | 越多粮耗越大 |
| 民力 | 建筑、大型工程、灾害恢复 | 稀缺的“国家行动能力” |
| 皇权 | 发布政策、压制部分政治风险 | 不直接等于王朝安全 |
| 民心 | 百姓整体状态 | 受粮荒、税赋、灾害、政策影响 |

## 4. 民力系统

### 4.1 民力不是普通库存

民力代表“一个月/一段时间内可以动员的劳动人口能力”。建筑建设、升级和大型工程都竞争同一资源。

### 4.2 基础规则

- 建造 1 座建筑：消耗 10 民力。
- 升级 1 座建筑：消耗 10 民力。
- 大型工程：可以长期锁定民力，例如修河道锁定 1000 民力，持续 12 个月。
- 被工程占用的民力不能再次用于其他建设。
- 民营提供持续民力，但需要消耗粮食。

### 4.3 修河道示例

```text
修复河东大堤

立即：锁定 1000 民力
持续：12 个月
每月：工程推进 1/12
完成：降低河东水患概率，提高粮食产出/治安
代价：这 1000 民力一年内不能用于其他工程
```

这类项目必须让玩家产生“现在救灾，还是先扩军/建仓”的真实冲突。

## 5. 多实例建筑

### 5.1 建筑不是单个全局等级

错误模型：

```text
官仓 Lv.3
```

正确模型：

```text
官仓 #1 Lv.3
官仓 #2 Lv.2
官仓 #3 Lv.1
...
```

同类型建筑默认最多 10 座；每座建筑拥有独立等级、建设状态、维护和产出。

### 5.2 建筑价值

玩家可以选择：

- 建更多 Lv.1 建筑：快速扩大基础能力，但增加维护。
- 少量建筑升高等级：集中资源提高效率，但建设速度慢。

因此“数量 vs 等级”本身就是一个决策。

### 5.3 建议首批建筑

| 建筑 | 核心产出 | 核心代价 |
|---|---|---|
| 官仓 | 储粮/赈灾能力 | 国库、民力 |
| 国库 | 财政效率 | 国库、民力 |
| 兵营 | 训练/军队上限 | 粮食、民力 |
| 武库 | 兵器产能/储备 | 国库、民力 |
| 工部作坊 | 工程/兵器效率 | 国库、粮食、民力 |
| 市舶司 | 商贸收入 | 国库、民力 |
| 民营 | 民力恢复 | 粮食、民力 |

## 6. 四大势力

初始满意度：

```text
士族 100
武将 100
百姓 100
豪强 100
```

### 6.1 不追求“四方都满意”

每个重大事件至少应该让两个势力产生不同方向的收益/损失，或者让一个势力获得明显利益而另一个势力付出明显代价。

例如：

```text
彻查贪腐
士族 100 → 90
百姓 100 → 110（实际封顶 100）
```

实际游戏状态始终限制为 0～100。

## 7. 势力危机与 Game Over

满意度只是“风险指标”，不是直接 Game Over 条件。

建议阈值：

| 满意度 | 状态 |
|---:|---|
| 80-100 | 支持 |
| 60-79 | 不满 |
| 40-59 | 紧张 |
| 20-39 | 危险 |
| 1-19 | 濒临反叛 |
| 0 | 进入反叛判定 |

真正失败必须来自叛乱、政变、民变等具体结果，而不是单纯“最低满意度低于某数字”。

### 7.1 反叛链

```text
满意度下降
 ↓
积怨增加
 ↓
组织力/煽动条件形成
 ↓
势力事件
 ↓
局部叛乱
 ↓
玩家选择平叛/安抚/妥协
 ↓
成功或失败
```

只有当叛乱无法控制、皇权崩溃、首都失守或其他明确终局条件成立时，才结束本局。

## 8. 为什么必须让玩家建设

如果玩家完全不建设，基础经济最多只能维持基本运转。

设计验收：

```text
0 建筑：维持/略亏
少量建筑：勉强增长
合理经营：稳定增长
过度建设：维护成本反噬
```

目标不是让玩家“永远缺资源”，而是让玩家始终面对**资源增长速度不足以覆盖所有需求**的问题。

## 9. 事件设计规范

每个选项必须提供：

```text
选择
↓
立即资源变化
↓
势力满意度变化
↓
州状态变化
↓
潜在长期后果
```

UI 必须显示：

```text
粮食      7,000 → 4,600  -2,400
兵器      1,200 →   780    -420
军队      1,800 → 1,620    -180
武将满意度 100 → 100        +12（封顶）
河东治安    55 → 69         +14
```

## 10. V0.5 试玩测试

### Test A：什么都不建

连续推进 12/24 个月。

预期：资源不会无脑增长；至少出现粮食/国库/民力等压力。

### Test B：疯狂建兵营

预期：军队增长带来粮耗，最终迫使玩家补粮或停止扩军。

### Test C：优先建设民营

预期：获得更多民力，但粮食压力增加。

### Test D：连续偏向同一势力

预期：另一势力满意度显著下降，并逐渐进入危险/反叛链。

### Test E：满意度 58

预期：游戏继续，不 Game Over。

### Test F：满意度 0

预期：进入反叛判定，而不是无条件立即结束。

## 11. V0.5 暂不做

- 真实历史地图
- 细化城市级地方地图
- 复杂战斗模拟
- 人物养成
- 多皇帝继承
- Steam 成就
- 联机

V0.5 的唯一目标是证明：**“皇帝每个月都必须做艰难取舍，而且不经营就会逐渐失去控制。”**
