# V0.5 经济压力验收表

> 用途：在接入月度循环前后，用固定策略测试经济是否仍会无脑滚雪球。

## 1. 核心验收

| 测试 | 操作 | 12个月预期 |
|---|---|---|
| A | 什么都不建、不主动扩军 | 资源不应持续高速净增长；至少出现明显财政/粮食/民力压力 |
| B | 连续建兵营并扩军 | 军粮和军费快速上升，迫使玩家补粮或停止扩军 |
| C | 优先建民营 | 民力增长明显，但粮食压力同步上升 |
| D | 优先建官仓 | 储粮/赈灾能力提高，但短期资源空间被占用 |
| E | 连续偏向一个势力 | 其他势力满意度持续下降，并进入危机链，而不是突然 Game Over |
| F | 将单个势力满意度压到 58 | 游戏继续运行 |
| G | 将单个势力满意度压到 0 | 进入该势力的反叛判定 |

## 2. 试玩时重点观察

每月记录：

- 国库：期初 → 月末 → 净变化
- 粮食：期初 → 月末 → 净变化
- 兵器：期初 → 月末 → 净变化
- 军队：期初 → 月末
- 民力：期初 → 月末
- 四大势力满意度
- 各州治安/民心/叛乱风险
- 建筑数量与等级
- 本月事件造成的变化

## 3. 平衡判断标准

### 健康

玩家可以通过建设改善国家，但必须付出资源与政治成本。

### 过于简单

连续跳过建设仍然资源暴涨；任何势力满意度都可以随便忽略。

### 过于困难

不进行特定建筑/政策组合就会在前 6 个月必然破产或叛乱。

## 4. V0.5 不接受的结果

- 资源无条件增长
- 建筑完全没有必要
- 四大势力满意度只是 UI 装饰
- 满意度 50～60 直接 Game Over
- 玩家能通过一种固定策略同时讨好所有势力
- 事件选项没有明确数据差异
