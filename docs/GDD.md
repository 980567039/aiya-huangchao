# 《哎呀，朕的皇朝怎么又亡啦》Game Design Document

**版本：V0.2**  
**阶段：Core Simulation Prototype**

## 1. 定位

玩家扮演架空王朝皇帝。制度、服饰、官制、社会结构和历史逻辑可以借鉴明朝及其他朝代，但不受真实历史人物和事件限制。

玩家只管理**主城区**。天下划分为五州，地方天灾、叛乱、战争等通过州级状态与奏折上报，不制作真实城市级地图。

核心体验：

> 皇帝不是寻找正确答案，而是在有限资源下决定“得罪谁”。

## 2. 一局

- 20岁登基
- 正常统治30年 / 360个月后退位
- 皇帝死亡、武将兵变、士族政变、农民起义或国家崩溃可提前结束
- 结束后根据统治路线、国家状态和主要势力关系生成历史评价

## 3. 五州

- 北朔州：边疆、军事
- 河东州：农业、粮食
- 中州：人口、政治、行政
- 江南州：粮食、税收、商业、士族
- 岭南州：商业、海外贸易

## 4. 四大势力

正式普通势力只有：

1. 士族
2. 武将
3. 百姓
4. 豪强

**皇权不是第五势力，而是国家属性。**

### 初始状态

四大势力新游戏开始时满意度统一为 **100**。新皇登基时各方默认支持，玩家随后通过圣旨、政策、战争、灾害和资源分配改变关系。

满意度是王朝存亡核心指标；影响力、组织力、财富、积怨、威慑等决定势力不满后的实际破坏能力。

## 5. 国家资源

- 国库
- 粮食
- 兵器
- 军队
- 皇权
- 民心

其中皇权不参与普通势力满意度模型。

## 6. 主城建筑

主城采用**多个独立建筑 + 独立升级**，不存在单一主城等级。

当前 Prototype 六类建筑：

| 建筑 | 主要作用 |
|---|---|
| 官仓 | 粮食 |
| 国库 | 财政、皇权 |
| 兵营 | 军队增长，但增加军粮压力 |
| 武库 | 兵器 |
| 工部作坊 | 兵器、财政 |
| 市舶司 | 贸易财政 |

每座建筑均为 Lv.1～Lv.5，并拥有独立建设成本、月度产出和维护成本。

## 7. 粮食与军队

军队和兵营都需要粮食。

```text
军队粮耗 = 军队人数 × 0.05
兵营粮耗 = 兵营等级 × 300
```

如果可用粮食不足以覆盖当月军队与兵营粮耗：

- 粮食归零
- 损失部分农民
- 损失部分士兵
- 百姓满意度下降
- 武将满意度下降
- 地方民心下降
- 叛乱风险上升

粮荒不是立即 Game Over，而是把资源危机转化为政治危机。

## 8. 月度循环

```text
州生产
→ 中央收入
→ 主城建筑
→ 军队/兵营粮耗
→ 粮荒检查
→ 人口/军队损失
→ 势力状态
→ 州状态
→ 事件
→ 奏折
→ 玩家决策
→ 后续事件
→ 叛乱/政变检查
→ 历史记录
```

## 9. 圣旨、奏折与事件

圣旨是玩家主动改变国家的主要手段。奏折是地方和势力利益进入主城区的主要信息入口。

每项重要决策应该同时产生收益、成本和势力后果。

事件包括灾害、粮荒、土匪、民变、官员贪腐、士族冲突、军队欠饷、豪强抗税、贸易机会和战争。

战争属于事件系统，不制作即时 RTS 战斗。

## 10. 叛乱

不同势力拥有不同的反抗方式：

- 百姓：流民 → 土匪 → 民变 → 农民军
- 武将：欠饷 → 抗命 → 兵变
- 士族：抵制 → 行政瘫痪 → 政变
- 豪强：抗税 → 资助土匪 → 地方割据

叛乱风险阶段：

- 0～39：正常
- 40～59：紧张
- 60～79：危险
- 80～99：临界
- 100：爆发

## 11. 政策技能树

四条路线：

- 仁政
- 集权
- 暴政
- 强兵

技能应提供新的决策能力，而不是只有简单数值加成。例如仁政可以开放特殊募捐，暴政可以强行镇压或掠夺势力财富，但会提高长期不满。

## 12. Prototype 目标

V0.1/V0.4 Prototype 的核心不是美术，而是验证：

- 四大势力是否真的成为玩家最关心的系统
- 主城建筑投资是否形成资源取舍
- 扩军是否因为粮食压力而产生代价
- 粮荒是否形成“缺粮 → 人口/军队损失 → 势力不满 → 政治危机”的连锁反应
- 玩家是否经常面对无法让所有人满意的选择
- 30年结束评价是否让玩家想再次开局
