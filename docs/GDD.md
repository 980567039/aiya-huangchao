# 《哎呀，朕的皇朝怎么又亡啦》Game Design Document

**版本：V0.1**  
**阶段：Core Simulation Prototype**

## 1. 游戏定位

玩家扮演一个**架空古代王朝**的皇帝。制度、服饰、官制、社会结构、人物原型与历史事件逻辑可以大量借鉴明朝及其他中国古代王朝，但**不受真实历史人物、真实朝代和真实历史事件限制**。

游戏不要求真实世界地图，也不要求城市级管理。玩家以**主城区**为决策中心，通过五州、奏折、圣旨、势力和资源掌握天下。

核心体验：

> **皇帝不是在寻找正确答案，而是在有限资源下选择“得罪谁”。**

## 2. 游戏周期与最终目标

最终设计为**约30年一局**。

- 玩家从**20岁**登基开始。
- 登基即代表本局唯一皇帝，不设计死亡后换皇帝继续游戏的继承人循环。
- 正常情况下经历约30年后结束本局并进入最终评价。
- 如果皇帝提前被武将、士族、百姓等势力推翻，游戏立即结束。
- 提前灭亡也会根据统治表现生成历史评价。

Prototype 可以采用更短的测试周期，但不能把测试周期当作最终游戏时长。

## 3. 核心循环

每月依次执行：

1. 州生产与国家资源结算
2. 人口、军队与行政消耗
3. 州状态变化
4. 国内外事件判定
5. 地方官生成奏折
6. 皇帝查看奏折并做出决策
7. 发布圣旨 / 批示
8. 圣旨按地方条件执行
9. 四大普通势力态度更新
10. 叛乱 / 政变风险检查
11. 月度总结
12. 进入下个月

## 4. 世界结构

V0.1 使用五个抽象州，不追求真实历史地图和城市级行政区划。地方天灾、叛乱、战争准备、财政异常等主要通过州级状态和奏折上报到主城区。

- **北朔州**：边疆、军事、马匹、军务压力
- **河东州**：农业、粮食、军屯
- **中州**：人口、政治、行政中心
- **江南州**：粮食、税收、商业、士族
- **岭南州**：商业、海外贸易、特殊资源

## 5. 四大普通势力 + 皇权

当前正式模型采用**4个普通势力 + 皇权国家属性**，不把皇权作为第五个普通势力。

### 四大普通势力

- **士族**：官职、土地、政治影响力、地方治理权
- **武将**：军饷、军权、军队规模、战功
- **百姓**：粮食、税负、治安、赈灾
- **豪强**：财富、商业、土地、地方自治

### 皇权

皇权是国家核心属性 / 资源，代表中央权威、政策执行能力和政治威慑，不拥有与普通势力完全相同的满意度模型。

普通势力拥有 `Satisfaction` 与 `Influence`。

核心设计原则：**不追求所有势力同时满意**。

## 6. 国家资源

核心资源：

- **国库**：税收、贸易、战争收益、官府支出、军费
- **粮食**：人口消费、军队补给、赈灾、战争消耗
- **兵器**：征兵、战争、平叛、军备
- **军队**：国家武力、平叛、战争、威慑
- **皇权**：中央权威、政策执行能力、政治威慑

后续可以增加人口、马匹、木材、白银等资源，但 Prototype 阶段不让资源过度膨胀。

## 7. 圣旨与决策

圣旨是玩家最核心的主动决策工具。第一版包括加税、减税、赈灾、征兵、裁军、扩军、查税、抄家、封赏武将、削弱武将等。

圣旨不是单纯按钮，而是国家政治行为。每项圣旨应尽可能同时产生收益、成本和势力后果。

## 8. 奏折

奏折是玩家了解地方情况的主要信息入口。

玩家可以看到真实的国家和州数据，同时通过奏折了解谁提出请求、为什么提出、谁获利、谁受损。

核心体验为：

> **数据透明 + 信息有偏差 + 利益关系复杂。**

奏折不是单纯猜真假，而是理解政治利益并做艰难选择。

## 9. 事件系统

事件包括自然灾害、国内政治、经济、外交和战争事件。

V0.1 事件包括旱灾、洪灾、蝗灾、粮荒、土匪、民变、官员贪腐、士族冲突、军队欠饷、豪强抗税、海贸 / 商贸机会和对外战争机会。

事件采用“条件 + 随机 + 世界状态”，而不是完全随机。

## 10. 战争

战争是**事件系统的一种高级事件**，不是独立 RTS 战斗系统。

例如对外出兵可以获得白银、战争威望、贸易利益和军事影响力，但消耗粮食、兵器、军队、国库并增加国内压力。

战争结果由国家军事准备、军队规模、将领能力、后勤和事件修正自动结算。Prototype 不制作即时战斗。

## 11. 叛乱与政变

可能出现农民起义、武将兵变、士族逼宫、地方割据和京城政变。

州叛乱风险综合考虑民心、地方忠诚、治安、土匪、饥荒、地方势力和驻军。

风险阶段：

- 0～29：稳定
- 30～49：不稳
- 50～69：骚乱
- 70～84：民变
- 85～100：高危

高风险后仍进行概率判定，给玩家留下干预机会。平叛需要消耗军队、粮食和兵器，同时可能导致其他地区防务下降。

## 12. 政策路线与技能树

政策路线是玩家长期成长与玩法差异的重要来源。

当前规划四条主要路线：

- **仁政**：民生、赈灾、减税、社会稳定
- **集权**：中央权威、行政控制、削弱地方势力
- **暴政**：高压、强征、镇压、快速获取资源
- **强兵**：军队、军备、征兵、战争能力

技能树通过特殊圣旨或被动效果改变玩家的政治选择。例如仁政技能可以允许一次特殊募捐；暴政技能可以强行镇压或掠夺势力财富，但提高不满和长期叛乱风险。

## 13. 30年结束与历史评价

本局在以下情况之一结束：

1. 皇帝正常完成约30年统治。
2. 皇帝被武将推翻。
3. 皇帝被士族集团推翻。
4. 皇帝被农民起义推翻。
5. 国家因长期财政、军事或政治崩溃而灭亡。

结束后生成“史书评价”。评价综合国祚、皇权、财政、民生、军事、稳定、地方控制、战争表现、政策路线、主要势力关系和王朝最终状态。

示例：中兴之主、守成之君、雄主、仁君、权谋之君、暴君、昏君、亡国之君。

最终评价应体现玩家自己的统治路线，而不是单一分数。

## 14. Prototype V0.1 设计目标

重点验证：

- 玩家是否真的感受到皇帝的艰难抉择
- 势力之间的利益冲突是否有趣
- 玩家是否会为了一个势力牺牲另一个势力
- 灾害、财政、军事、政治是否形成连锁反应
- 战争是否是高风险高收益决策
- 玩家是否产生“如果当时选择另一项”的后悔
- 玩家能否理解王朝为什么走向某种结局
- 30年后的历史评价是否让玩家想再开一局

## 15. Prototype 与最终游戏的边界

当前 Prototype 可以存在：

- 短于30年的测试周期
- 少量事件和技能
- 简化资源
- 临时 UI
- 简化主城区
- 尚未实现完整人物系统
- 尚未实现完整战争表现

这些属于实现阶段，不代表最终设计取消。
