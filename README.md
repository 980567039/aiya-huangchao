# 《哎呀，朕的皇朝怎么又亡啦》

> 一个“皇帝决策 + 政治势力博弈 + 国家经营 + 历史故事生成”的架空王朝模拟游戏。

**当前阶段：Prototype V0.1 / Sprint 1**

---

## 1. 游戏简介

玩家扮演一位 **30岁登基的皇帝**。

一局游戏约 **30年 / 360个月**。玩家不需要管理真实地图上的每一座城市，而是坐镇主城区，通过来自五州的**奏折、急报与事件**了解天下，并不断做出艰难决策。

游戏的核心不是“建立一个永远繁荣的王朝”，而是：

> **在不同势力的利益冲突、资源压力、天灾、战争与叛乱中，努力让自己的王朝活到30年。**

30年结束后，无论是中兴、平庸、暴政，还是被武将、士族或农民推翻，都会形成属于这位皇帝的最终历史评价。

---

## 2. 核心玩法

```text
五州
 ↓
资源生产
 ↓
中央财政 / 粮食 / 军队
 ↓
四大势力博弈
 ↓
天灾 / 社会 / 政治事件
 ↓
奏折
 ↓
皇帝决策
 ↓
圣旨 / 政策技能
 ↓
Effect
 ↓
国家与势力状态变化
 ↓
新的问题
 ↓
叛乱 / 平叛 / 政变
 ↓
历史记录
 ↓
30年结局评价
```

### 四大势力

- **士族**：重视政治影响力、官制、土地与税制
- **武将**：重视军饷、军权、战争与军功
- **百姓**：重视粮食、税赋、治安与生存
- **豪强**：重视财富、地方利益与地方控制力

### 五州

第一版固定为：

1. 北朔
2. 河东
3. 中州
4. 江南
5. 岭南

不追求真实历史地图。地方问题主要通过州级状态和奏折传达到主城区。

## 3. 皇帝的主要决策

玩家可以：

- 阅读奏折
- 批准 / 驳回请求
- 发布圣旨
- 调拨粮食与财政
- 征兵 / 派兵
- 赈灾
- 平叛
- 使用政策技能
- 在势力之间进行利益取舍

核心设计原则：

> **大多数重要决策都应该让某个势力获益，同时让另一个势力付出代价。**

例如：

```text
同意士族减税
→ 士族满意度 +
→ 中央收入 -
→ 百姓可能受益
→ 军费可能不足
```

或者：

```text
强行镇压豪强
→ 国库 +
→ 皇权 +
→ 豪强满意度 --
→ 豪强积怨 ++
→ 后续可能资助土匪 / 地方割据
```

## 4. 政策路线

政策路线是本作的重要成长与爽点系统。

当前规划四条路线：

```text
仁政
集权
暴政
强兵
```

第一版每条路线只实现少量技能，用于验证“不同治国风格是否真的改变玩法”。

例如：

### 仁政

通过赈灾、减税、施恩等方式提高民心，但通常需要付出财政或资源代价。

### 集权

强化中央与皇帝对地方、官僚和势力的控制。

### 暴政

允许皇帝通过高压、强征、抄没等方式快速获取资源或压制风险，但会积累长期仇恨。

### 强兵

强化军队、军屯、征兵与战争能力，但军队扩张会增加长期资源消耗，并可能提高武将势力。

## 5. 月度游戏循环

游戏以“月”为核心模拟单位。

```text
进入新月份
 ↓
州生产
 ↓
中央收入
 ↓
军队 / 行政 / 战争消耗
 ↓
势力状态更新
 ↓
州状态更新
 ↓
持续中的政策 / 圣旨生效
 ↓
事件判定
 ↓
生成奏折
 ↓
皇帝处理奏折
 ↓
Action → Effect
 ↓
后续事件
 ↓
叛乱判定
 ↓
月末历史记录
 ↓
下个月
```

## 6. Effect 架构

所有游戏状态变化统一通过：

```text
Action
 ↓
Effect Engine
 ↓
GameState
```

实现技能、圣旨、事件和奏折时，不允许 UI 直接修改游戏状态。

例如：

```text
【开仓赈灾】

粮食 -3000
国库 -500
百姓满意度 +8
州治安 +2
```

最终都由 Effect Engine 统一处理。

相关设计：

- [`docs/gameplay/effect-system-v0.3.md`](docs/gameplay/effect-system-v0.3.md)

## 9. Prototype 开发原则

### 先验证玩法，再做美术

V0.1 不制作正式美术、复杂地图、战斗动画和大量角色立绘。

### 先完成闭环，再增加内容

不要一开始做100个事件。先用少量事件验证游戏循环。

### 数据驱动

尽量把数值和事件配置放入 `data/`，避免硬编码。

### GameState 是核心

所有关键游戏状态都必须可以从 GameState 得到。

### Effect 是唯一状态变化入口

技能、圣旨、事件、奏折等系统统一通过 Effect 修改状态。

### 失败也是游戏内容

皇帝被武将推翻、士族逼宫、农民军攻入京城，都应该成为完整的历史结局，而不是简单的“失败画面”。

## 11. 当前版本目标

### Prototype V0.1

不是做一个“看起来像游戏”的 Demo。

而是验证：

> **皇帝每个月面对的问题，是否真的能让玩家纠结。**

第一阶段最重要的问题：

- 玩家是否会在两个选项之间犹豫？
- 不同政策路线是否有明显区别？
- 资源是否产生足够压力？
- 四大势力是否会形成真实的利益冲突？
- 事件是否会产生连续后果？
- 叛乱是否既可怕又可以处理？
- 玩家是否会因为过去的决定而后悔？

如果答案是“是”，再继续扩大游戏规模。

## 13. 项目愿景

希望最终做成一款：

> **“看起来是在当皇帝，实际上是在处理一堆永远处理不完的问题。”**

玩家不是为了建立完美帝国而玩。

而是为了看看：

> **“如果朕当30年皇帝，最后历史会怎么评价我？”**
